### 废案：远程办公的一百种无聊方式（其五）

我在重新校准模拟宇宙的命途权重，星核小鬼的通信请求弹了出来。接了，没马上看。

他最近学了个新招：在消息里直接写 `@板砖`，板砖自己读、自己开工，不用经我的手。

是好事，前提是他得把任务写清楚。`@板砖` 一进指令栈，我就不替他补需求了，板砖只认字面。写不清楚，它要么瞎猜，要么干到一半停下来，等一句永远不会来的解释。

瞄了一眼预览。哦？这回写得还不算太烂。

````text
+export function fib(n: number): bigint {
+  if (n < 0) throw new RangeError("fib: n must be non-negative");
+  if (n < 2) return BigInt(n);
+  let a = 0n, b = 1n;
+  for (let i = 2; i <= n; i++) {
+    [a, b] = [b, a + b];
+  }
+  return b;
+}
```
````

让他直接使唤板砖，我一开始是不太乐意的：需求写没写清楚，这个责任就从我这儿挪到他那儿去了。写得好，皆大欢喜；写得烂，板砖就朝着错误的方向烧算力。

跑下来倒还行。里面有个我没设计、但确实在转的循环：板砖照他写的跑出一堆垃圾，收拾垃圾的也是他自己。比他写三遍草稿、我打回去两遍快多了。
